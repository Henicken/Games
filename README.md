# ⚽🎮 Web Projects Collection

Hey there! Welcome to my repository. 👋 This is a collection of two fun and interactive web applications I built using **HTML5**, **CSS3**, and **JavaScript**: an informational dashboard for the Ethiopian Men's National Football Team and a classic, browser-based Rock, Paper, Scissors game. 

---

## 📂 What's Inside?

### 1. 🇪🇹 Ethiopian National Football Team Statistics (`Games/Football/`)
As a big football fan, I wanted to create a dedicated web space to showcase the Ethiopian Men's National Football Team (The Walias). This project organizes team data and player profiles into a clean, easy-to-read interface.
* **Core Files:**
  * `Team.html`: The main webpage layout and structure.
  * `Cards.js`[cite: 2]: JavaScript code responsible for dynamically generating and rendering player cards.
  * `styles.css`[cite: 2]: Custom styling to give the page a clean, polished look.

### 2. ✂️ Rock, Paper, Scissors Game (`Games/Rock/`)
A classic hand game brought to the browser! You can play right against the computer, with the script handling random moves and keeping track of the scores in real-time.
* **Core Files:**
  * `index.html`: The game's user interface and layout[cite: 3].
  * `Rock,Paper.js`[cite: 3]: The game logic that handles player choices, computer decisions, and score updates[cite: 3].
  * `styles.css`[cite: 3]: Custom styles that bring the game interface to life[cite: 3].

---

## 🛠️ Built With

I built these projects from scratch using core web technologies:
* **HTML5** for structuring the content.
* **CSS3** for layout design and styling.
* **JavaScript (ES6)** for handling DOM manipulation and game logic.
